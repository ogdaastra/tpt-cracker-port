Source code

This site runs Cracker1000's Mod for The Powder Toy (v55.1, based on The Powder Toy of January 2023), compiled to WebAssembly, with extra elements from TPT Ultimata, a newer Cracker1000's Mod branch and Jacob1's Mod (listed in ADDED_ELEMENTS.md). It is free software under the GNU General Public License, version 3.

Corresponding source

  • Complete source of this build (commit @COMMIT@): the game, the mod, the WebAssembly port changes, this page and the build scripts.
  • FFTW 3.3.10 source (GPL-2.0-or-later), linked into the game for gravity.
  • Licenses of the other bundled libraries (Lua 5.1.5, JsonCpp 1.9.5, Eigen 3.3.7, SDL 2.32.8, zlib, libpng, bzip2, Emscripten runtime).

Upstream projects: Cracker1000's Mod, TPT Ultimata, Jacob1's Mod, The Powder Toy.

Building it yourself

On Linux (or WSL2) with git, Python 3, Meson ≥ 0.61, Ninja, pkg-config, a host C++ compiler and curl:

./wasm/build-deps.sh   # Emscripten @EMSDK@ (installed automatically), Lua, JsonCpp, FFTW
./wasm/build.sh        # build-wasm/ and the static site in dist/

See PORT_LOG.md in the source archive for what was changed for the browser and why.
