# Elements added to this web version

On top of Cracker1000's Mod v55.1. Every one of them is GPL-3.0 code from the mod named, adapted to this
code base (see `PORT_LOG.md`, section 13, for what was changed and why). Generated from the element sources.

The longest menus were split into five new ones, in a second column of menu buttons right of the classic
side bar: **Life and Nature** (creatures, plants, food, body parts), **Space and Gravity** (stars, black and
white holes, space-ship parts), **Characters and Vehicles** (stickmen, fighters, tanks, gunship),
**Circuits** (TPT Ultimata's voltage-simulation parts) and **Metals**. The classic menus keep their numbers,
which Lua scripts use. On the web page, the **Elements** button opens a searchable list of every menu; the
in-game search button finds any element by name too.

## Other additions from TPT Ultimata

- **Walls:** I-WALL (particles inside can't be destroyed), FARADAY WALL (WIFI, ETRD, EMP and portals don't connect across it), ONE WAY WALL (use the line tool to set the direction).
- **Game of Life rules:** LWDH, SERV, VT45, FMZE, LFOD, ANTI, INVL, HTRE, IBAL, RULH, CRCF, GEMS, PLIF, DOTS.
- **Tools:** DECO (sets deco colour to the element colour), NORM (normalises temperature and pressure), EROD (erodes edges), SLOW and FAST (time dilation).
- **Engine features the elements use:** circuit solver (VOLT, RSTR, CPTR, INDC, ...), vehicles (CYTK, TANK, GNSH, HRSE), moving solids (MVSD), quantum states (ION, QLOG), stress (TRUS), time dilation (TIME, CBMB), stasis fields (EXFN), NOTE sound and `tpt.play_sound()`.
- **Renamed because the name was taken:** Ultimata's ROCK is ROCK2 and its SLCN is SLCN2. Ultimata elements whose names Cracker already used (BEE, CLUD, CMNT, COPR, CSNS, MGNT, PINV, RADN, SEED) keep Cracker's version.
